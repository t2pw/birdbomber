================================================================================
Game Concept & Specification Document: "Project Sky Sniper" (Working Title)
================================================================================

■ 1. ゲーム概要
--------------------------------------------------------------------------------
【コンセプト】
プレイヤーが「鳥」の一人称視点（FPS）となり、近未来のサイバーな都市の上空を飛行しながら、
眼下の道路を爆走する「生意気なオープンカー」をロックオンし、タイミングよく排泄物（フン）を
命中させてスコアを競う、スタイリッシュ・サイバー・バカゲー。

【ターゲットプラットフォーム】
・スマートフォン（iOS / Android）
・縦画面（ポートレート）プレイ、片手ワンタップ操作

【デザイン方針】
・「安っぽさ（クソゲー感）」を徹底的に排除する。
・おバカなテーマ（フンを落とす）だからこそ、UIやエフェクトを「戦闘機のコックピット」や
  「最新鋭のハドディスプレイ（HUD）」のように徹底的にスタイリッシュかつサイバーに仕上げる。


■ 2. 画面構成とUI（一人称視点 / 疑似3D）
--------------------------------------------------------------------------------
画面奥の消失点から、道路や背景（ビル群など）が手前に向かってビュンビュンと流れることで、
鳥が高速で飛行している「没入感」と「疾走感」を2Dの疑似3D表現で実現する。

【画面レイアウトイメージ】
+--------------------------------------------------+
| [ SCORE: 128,500 ]          [ BOMB GAGE: |||||| ] |
|                                                  |
|                      ▲                          |
|                     / \  (消失点・道路の奥)       |
|                    /   \                         |
|                   /  [■] <- ロックオンされた車両   |
|                  /  LOCK  (奥から手前へ高速接近)   |
|                 /    ON  \                       |
|                /          \                      |
|               /            \                     |
|              /      〇      \                    |

|            /                  \                  |

|          /          (〇)        \                |
+--------------------------------------------------+
|          [ 画面のどこをタップしても投下！ ]          |
+--------------------------------------------------+

【主要なUI要素】
1. 中央レティクル（照準）:
   画面中央に固定されたネオンカラーのサイバーな照準。
2. ロックオン枠:
   出現したオープンカーを自動検知し、緑や赤のデジタル枠で追尾する。
3. 着弾予測サークル:
   「今フンを落としたら、地面（道路）のどこに着弾するか」をリアルタイムに示す光るサークル。
   ※ 高低差による難易度を解消し、ゲーム初心者でも遊びやすくするための重要UI。


■ 3. コアゲームシステム & 操作方法
--------------------------------------------------------------------------------
【通常攻撃：スナイプ投下】
・操作: 画面をシングルタップ（場所はどこでも可）。
・挙動: 鳥の位置からフンが放たれ、着弾予測サークルに向けて落下する。
・快感のツボ: サークルの中にオープンカーが進入した瞬間を狙う「偏差射撃」の楽しさ。

【必殺技：急降下爆撃（ボム）】
・発動条件: ターゲットを汚すことで「ボムゲージ」が満タンの時に、画面を長押し。
・演出の流れ:
  1. 画面に「DIVE MODE INITIATED（急降下モード起動）」のアラートが点滅。
  2. BGMが一瞬ミュートになり、激しい羽ばたき音と風切り音（ゴオオォォ）のみに。
  3. カメラが地面に向かって急激にズーム（急降下）し、画面内の全車両を強制ロックオン（赤枠）。
  4. 鳥が急上昇に転じると同時に、ロックオンした全車両に広範囲のフンを絨毯爆弾のように自動着弾。
  5. 「COMPLETE OUTDESTROY!（完全汚染）」の文字がスタイリッシュに表示され、通常視点に戻る。
・用途: 画面内に車が溢れかえって処理しきれないピンチ時の画面一掃、および一気の大得点チャンス。


■ 4. 「安っぽさ」を完全に回避する演出のツボ（ノベルゲーム的アプローチ）
--------------------------------------------------------------------------------
1. スマホの振動（触覚フィードバック）の連動:
   フンが車やドライバーに命中した瞬間に、スマホが「ニュクッ」と短く小気味よく震える。
2. スローモーション（キルカメラ）演出:
   高得点ターゲットへのジャストミート時、命中直前の数秒間が映画のようにズーム＆スロー（またはモノクロ化）になり、着弾の瞬間をドラマチックに魅せる。
3. ターゲットプロフィールのカットイン:
   車が奥から出現した際、画面隅に「TARGET: 生意気なIT系CEO」「SPEED: 140km/h」といったスタイリッシュなテキスト情報をタイピング風に表示。
4. ドライバーのリアクション（顔グラ・セリフ）:
   命中時、「うわああ！俺の高級車が！」といった絶妙にコミカルなセリフや顔グラフィックをカットインさせ、実況プレイなどでのリアクション・ツッコミどころを作る。


■ 5. マネタイズ設計
--------------------------------------------------------------------------------
【基本プレイ無料（F2P）＋広告・軽課金モデル】
1. リワード広告（動画広告）:
   ・ゲームオーバー時、「動画を見たらフンが巨大化して1回だけ復活」。
   ・ステージ開始前、「動画を見て初期弾数を2倍にする」。
2. スキン（見た目）課金・ガチャ:
   ・ゲーム性能は変えず、鳥の見た目（サイバーハト、漆黒のカラス、不死鳥など）や、
     フンのエフェクト（ネオンカラー、スプラッシュエフェクト変更）を変更できる。


■ 6. AI（Codex / Claude Code）へのファースト指示プロンプト例
--------------------------------------------------------------------------------
開発の第一歩として、AIエンジンへ最初に投入するプロンプトの構成：

「Unity 2Dを使用し、スマートフォン向けの縦画面ゲームを制作します。
鳥の一人称視点（フライトゲーム風）のベースとなるプロトタイプを作成したいです。
コードが書けない初心者向けに、オブジェクトの配置手順も含めて教えてください。

【実装したいこと】
1. 画面中央奥の『消失点』から、画面手前に向かって道路の白線や背景（2Dのシンプルな矩形や画像）が
   ビュンビュンと流れてくる、疾走感のある背景ループのC#スクリプト。
2. 画面中央に、固定された『円形の照準（レティクル）』のUIを表示する手順。」
