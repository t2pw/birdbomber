# Project Sky Sniper Prototype

Unity実装前に、コアの遊びを検証するためのブラウザ版プロトタイプです。

## 起動

`index.html` をブラウザで開きます。

## 操作

- `START SORTIE`: ゲーム開始
- タップ / クリック: 照準中心へ投下。装填1.6秒・同時1発のみ
- 長押し: ボムゲージ100%時に急降下爆撃

## コア設計：爆撃手視点の一射一殺

- カメラは鳥基準の真下見下ろし。鳥の影がある照準中心が常に着弾点
- 地面は高速、車は相対速度で低速スクロールし、鳥が車に追いついていく感覚を作る
- ロック中の車には「**+0.9sゴーストフレーム**」（0.9秒後の未来位置の破線枠）が表示される
- ゴーストが照準中心に重なった瞬間（サークルがピンクに変化＋FIRE!表示）がジャストタイミング
- 装填に1.6秒かかるため連打は不可能。1発外すとその車はほぼ取り逃しになる緊張感

## 実装済み

- 縦画面の真下見下ろし道路
- 3レーン車両スポーン（鳥基準の相対速度ペーシング）
- 車両ごとの相対速度、スコア、サイズ差
- 照準中心固定＋ゴーストフレームによるタイミング射撃
- ロック車両レーンへの自動バンク追従
- 鳥の影、翼端、ビル屋上パララックス、2層スクロール
- 装填制（1.6秒、リロードリング＋RELOADING表示）
- HIT / JUST SNIPE / MISS、JUST時ヒットストップ
- コンボ、スタイルランク、スコア倍率
- ライフ制（3）、OVERSHOOT取り逃しペナルティ
- ボムゲージと全体攻撃
- 簡易HUD、ヒット演出、振動対応端末でのバイブレーション

## 次に検証すること

- 2層スクロール速度差だけで「追いついている」と直感できるか
- OVERSHOOTの喪失感が「緊張」になっているか「ストレス」か
- ストーク時間3〜6秒で「待つ楽しさ」が成立するか
- 自動バンク0.6秒が「自分で狙っている感」を損なわないか
- ゴーストフレームの読みやすさ（FIRE!表示が補助として強すぎないか）
