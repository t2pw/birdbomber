# Project Sky Sniper Prototype

Unity実装前に、コアの遊びを検証するためのブラウザ版プロトタイプです。

## 起動

`index.html` をブラウザで開きます。

## 操作

- `START SORTIE`: ゲーム開始
- タップ / クリック: ロック中ターゲットの0.9秒後の予測位置へ通常投下
- 長押し: ボムゲージ100%時に急降下爆撃

## 実装済み

- 縦画面の疑似3D道路
- 3レーン車両スポーン
- 車両ごとの速度、スコア、サイズ差
- ロック中ターゲットに追従する着弾予測サークル
- 0.9秒落下ディレイ
- HIT / JUST SNIPE / MISS
- コンボ、スタイルランク、スコア倍率
- ライフ制、取り逃しペナルティ
- ボムゲージと全体攻撃
- 簡易HUD、ヒット演出、振動対応端末でのバイブレーション

## 次に検証すること

- 落下時間0.9秒が直感的か
- 車速とスポーン間隔が気持ちよいか
- 着弾サークルの追従が見やすいか
- HIT判定の楕円サイズが甘すぎないか
